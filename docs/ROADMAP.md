# Roadmap

แนวทางต่อยอดของโปรเจกต์ เรียงจากสิ่งที่คุ้มที่สุดก่อน

---

## ระยะสั้น (ต่อจากสถานะปัจจุบัน)

- [ ] **Instrumented test บนอุปกรณ์** — ทดสอบ `TrafficLightAnalyzer` ด้วยเฟรมจำลอง
      (`ImageProxy` ปลอม) และ `OverlayView` ด้วย `Canvas` ปลอม เพื่อให้ CI ครอบคลุมมากขึ้น
- [ ] **เทรนโมเดลจริง + แนบตัวเลขผลประเมิน** (mAP/recall ต่อคลาส) ลงใน README
- [ ] **เพิ่ม `TrafficLightGateTest` ให้ครอบคลุมเคส 2 เฟรมสลับ + ขนาดกรอบต่างกัน**
- [ ] **`Lint` baseline** — เก็บ lint ปัจจุบันเป็น baseline แล้วทำให้ lint เป็น blocking step ใน CI
- [ ] **รองรับสระสี (color fallback)** — ถ้าโมเดลไม่เห็นไฟ แต่พื้นที่กรอบมีไฟสว่างสีเขียวชัด
      ให้ยืนยันด้วยการวิเคราะห์ฮิสโตแกรมสี เพื่อลด false negative ตอนกลางคืน

## ระยะกลาง

- [ ] **YOLO raw-anchor decode** — ถอดรหัส anchor + NMS เต็มรูปแบบ เพื่อรองรับโมเดล
      ที่ไม่ทำ post-process ในกราฟ (ปัจจุบันต้องพึ่ง `TFLite_Detection_PostProcess`)
- [ ] **Tracking ต่อเนื่อง (IoU/SORT-style)** — ให้ไฟหนึ่งดวงมี id เดียวตลอดช่วงที่เห็น
      แล้วผูก debounce กับ id → แม่นขึ้นเมื่อมีไฟหลายดวงหรือกล้องสั่น
- [ ] **ปรับภาพก่อนเข้าโมเดล** — gamma/CLAHE สำหรับกลางคืน, ตรวจความสว่างเพื่อข้ามเฟรมที่มืดเกิน
- [ ] **เสียงพูดเตือนภาษาไทย** — `TextToSpeech` ผ่าน interface `Alerter` ตัวใหม่ เช่น "ไฟเขียว ไปได้"
- [ ] **หน่วยความจำแบบ zero-copy** — ใช้ `ImageProxy` → `ByteBuffer` ตรงเข้าอินพุตโมเดล
      (ลดการสร้าง Bitmap ต่อเฟรม) เพื่อให้ได้ 15–20 fps บนเครื่องรุ่นกลาง

## ระยะยาว (ขยายเป็นระบบจริง)

- [ ] **ประเมินความเสี่ยงชน (TTC/TTC-like)** — ใช้การขยายขนาดกรอบต่อเวลา + ความเร็วจาก GPS
      เพื่อเตือนเฉพาะเมื่อไฟเขียวแต่รถคันหน้าเบรกอยู่
- [ ] **บันทึกทริป (Room)** — log การเจอไฟแต่ละครั้ง (เวลา/คลาส/confidence) ทำรายงานหลังขับ
- [ ] **กล้องคู่/ความละเอียดสูง + ROI** — จำกัดพื้นที่ตรวจจับเฉพาะกลางถนน ลด noise จากข้างทาง
- [ ] **โมเดลหลายตัวตามสภาพแสง** — สลับ night model / day model อัตโนมัติตามค่าความสว่างภาพ
- [ ] **Compose UI** — ย้าย `OverlayView` เป็น Compose `Canvas` + `collectAsState()`
- [ ] **บน Android Automotive / AAOS** — ปรับให้รันเป็นแอปในรถ (จอใหญ่, หลายกล้อง)
- [ ] **Pipeline ประเมินอัตโนมัติ** — สคริปต์รันวิดีโอทดสอบ + ตรวจว่าเสียงดัง/เงียบตรงกับ
      ground truth ของไฟในคลิป (regression test ระดับพฤติกรรม)

## สิ่งที่จะไม่ทำ (โดยตั้งใจ)

- **ไม่ทำ automatic braking/steering หรือสั่งการรถ** — เป็นแอปเตือนเท่านั้น
  การสั่งการต้องผ่านมาตรฐานความปลอดภัยระดับยานยนต์ (และควรใช้เซนเซอร์เฉพาะทาง ไม่ใช่กล้องมือถือ)
- **ไม่อัปโหลดภาพขึ้นคลาวด์** — ทุกอย่างประมวลผลบนอุปกรณ์ เพื่อความเป็นส่วนตัวและความหน่วง
